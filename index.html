Como funciona?

Recuperação direta no navegador, passo a passo.

  1. Escolha a pasta data. É a pasta do MySQL que tem o arquivo ibdata1. Se o banco está num .rar ou .zip, extraia antes. Você pode escolher a pasta pelo clique ou arrastá-la para a tela.
  2. Dê um nome. Ele vira o nome do arquivo .sql e identifica a recuperação no histórico.
  3. Recupere. No Chrome e no Edge você escolhe onde salvar o .sql e ele é gravado direto no disco, tabela por tabela. No Firefox e no Safari o dump fica na memória e é baixado no fim (só serve para bancos pequenos).
  4. Sem servidor MySQL. O Python roda dentro do navegador (Pyodide), lê as páginas do ibdata1 e refaz a estrutura pelo dicionário do InnoDB e pelos .frm. Os arquivos não saem do seu computador; só o Pyodide é baixado da internet.
  5. Confira. O relatório mostra cada tabela, os registros lidos, os avisos de registros ilegíveis ou páginas perdidas e o SHA-256 do dump.
  6. Importe. Num MySQL, rode mysql -uroot -p < banco.sql.
Esta versão gera só o dump .sql. Não gera pasta data nova, não lê tabelas MyISAM, rotinas e eventos, nem tabelas COMPRESSED, e não aceita MySQL 8.0 nem entrada .sql. Registros apagados há pouco tempo podem reaparecer. Para esses casos use o programa de desktop.
